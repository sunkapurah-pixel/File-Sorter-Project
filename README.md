# File-Sorter-Project
Python Automation Script for sorting files based on their extensions. The project uses OS module, exception handling, user input, and log generation to automatically organize files into folders.

## Overview

This project is a Python-based automation script that organizes files into folders based on their file extensions. It improves file management by automatically sorting files and generating logs of all operations.

## Features

File sorting by extension

User-defined folder path

Automatic folder creation

Operation logging with timestamps

Exception handling for invalid paths and errors

## Technologies Used
Python

os

shutil

datetime
## How to Run

Open the project in Python or Jupyter Notebook.

Enter the folder path containing files.

Run the script.

Files will be sorted into extension-based folders automatically.

## Sample Output

Files sorted successfully!

## Advantages

Automates file organization and reduces manual effort.

Saves time by sorting files automatically.

Improves file management and accessibility.

Generates logs for tracking operations.

Easy to use and beginner-friendly.

## Limitations
Sorts files only based on extensions.

Does not analyze file content.

Requires correct folder paths from the user.

Limited to local system files.

Cannot handle duplicate file names in advanced scenarios without modification.

## Conclusion:
The File Sorter Automation Script successfully organizes files into extension-based folders, making file management easier and more efficient. It demonstrates the use of Python automation, user input handling, exception handling, and log generation.
